FOCUSSTUDY
Student Planner Web App

QUICK START

1. Extract this ZIP file.
2. Open FocusStudyPlanner.html.
3. Recommended browser: Google Chrome or Microsoft Edge.
4. No installation is required.

IMPORTANT

FocusStudy stores your planner data locally in your browser.

Use Settings > Data > Export My Data regularly to create backups.

To restore:
Settings > Data > Import Backup
