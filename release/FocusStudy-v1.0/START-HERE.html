Your Data and Backups

Your planner data is stored locally in your browser on the device where you use FocusStudy.

Back up regularly: Because FocusStudy stores your data locally, export a backup regularly if your planner information is important to you.

Export a backup

Open FocusStudy, then go to Settings > Data > Export My Data. This creates a JSON backup file.

Restore a backup

Go to Settings > Data > Import Backup, then choose your exported focusstudy-backup-YYYY-MM-DD.json file.

To move to another computer: export your data on the old computer, move the JSON backup file, open FocusStudy on the new computer, and import the backup. No cloud account is required.

If you clear browser or site data, local planner information may be removed. Use backups to protect important planner data.

Settings

Use Settings > Appearance to choose Light, Dark, or System mode.

Clear All Data: Settings > Data > Clear All Data permanently resets FocusStudy data in that browser. Export a backup first if you want to keep your planner information.

Troubleshooting

  • The file does not open

    Right-click FocusStudyPlanner.html, choose Open With, then select Google Chrome or Microsoft Edge.

  • Your data is missing

    Confirm you are using the same browser and device, check whether browser data was cleared, and restore your latest FocusStudy backup if available.

  • You are using a different computer

    FocusStudy does not automatically sync between devices. Use Export My Data and Import Backup.

  • The app behaves unexpectedly inside the ZIP

    Extract the folder first, then open FocusStudyPlanner.html from the extracted folder.
